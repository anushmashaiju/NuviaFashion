# Nuvia - Fashion E-Commerce Website

Nuvia is a modern, full-featured e-commerce website for fashion products built with **Node.js, Express, MongoDB, and EJS**. It offers a seamless shopping experience for users and a comprehensive admin dashboard for managing products, orders, and users.

---

## 🌟 Features

### User Features
- User authentication with **signup/login**, including **OTP verification**.
- Login/signup with **Google OAuth**.
- View **products and categories** with maximum offers and category-wise filtering.
- Add products to **cart** and **wishlist**.
- **Buy Now** and **Checkout** with multiple payment options:
  - Razorpay
  - Cash on Delivery (COD)
  - Wallet system
- **Apply coupons** during checkout.
- Manage **addresses**, set default address, and update profile.
- View **orders**, request returns, and download **invoices**.
- Refer & Earn system.
- Responsive design for **desktop and mobile**.

### Admin Features
- Admin login/logout with secure session management.
- Manage **users**: view, block/unblock.
- Manage **categories and products**: add, edit, delete, block/unblock.
- View **orders**, approve/cancel returns, and update order statuses.
- Create and manage **coupons**.
- Generate **sales reports** in PDF and Excel formats.
- Dashboard displays **best-selling products, categories, brands, revenue stats, and ledger**.

---

## 💻 Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS, Bootstrap
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js (Local + Google OAuth)
- **Payment:** Razorpay
- **File Uploads:** Multer, Cloudinary
- **Session Management:** Express-session
- **Other Tools:** SweetAlert2, Font Awesome, Owl Carousel
